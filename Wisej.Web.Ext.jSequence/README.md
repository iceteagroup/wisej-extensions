# jSequence

**Draws UML sequence diagrams from a simple text description, based on js-sequence-diagrams, with a click event for the diagram elements.**

## Installation

The extension is published on NuGet as **`Wisej-{version}-jSequence`**, where `{version}` is the major version of Wisej.NET you use. For example, for Wisej.NET 4:

```
dotnet add package Wisej-4-jSequence
```

Keep it at the same version as the `Wisej-4` package. See [Installing an extension](https://docs.wisej.com/extensions/#installation).
