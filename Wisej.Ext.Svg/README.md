# Svg Renderer

**A client-side SVG renderer based on Snap.svg. It's a dependency of the FluentUI and Lucide icon packs and takes over the rendering of every SVG image in the application once it's referenced.**

## Installation

The extension is published on NuGet as **`Wisej-{version}-Svg`**, where `{version}` is the major version of Wisej.NET you use. For example, for Wisej.NET 4:

```
dotnet add package Wisej-4-Svg
```

Keep it at the same version as the `Wisej-4` package. See [Installing an extension](https://docs.wisej.com/extensions/#installation).
