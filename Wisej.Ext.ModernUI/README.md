## Installation

The extension is published on NuGet as **`Wisej-{version}-ModernUI`**, where `{version}` is the major version of Wisej.NET you use. For example, for Wisej.NET 4:

```
dotnet add package Wisej-4-ModernUI
```

Keep it at the same version as the `Wisej-4` package. See [Installing an extension](https://docs.wisej.com/extensions/#installation).
