# Amazon S3

**A file system provider that exposes an Amazon S3 bucket to the Wisej.NET file dialogs and to any code that works with IFileSystemProvider.**

## Installation

This extension isn't published on NuGet. Add the project in this folder to your solution and reference it from your application.

## Source code

This folder contains the full source code of the extension. You can use it to see how it works, build a modified copy, or start your own extension. If you fix or improve it in a way that could help others, please open an issue or a pull request.
