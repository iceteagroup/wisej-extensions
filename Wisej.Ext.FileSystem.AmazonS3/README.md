**A file system provider that exposes an Amazon S3 bucket to the Wisej.NET file dialogs and to any code that works with IFileSystemProvider.**

## Installation

The extension is published on NuGet as **`Wisej-{version}-AmazonS3`**, where `{version}` is the major version of Wisej.NET you use. For example, for Wisej.NET 4:

```
dotnet add package Wisej-4-AmazonS3
```

Keep it at the same version as the `Wisej-4` package. See [Installing an extension](https://docs.wisej.com/extensions/#installation).
