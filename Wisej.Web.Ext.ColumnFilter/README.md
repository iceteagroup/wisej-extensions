# ColumnFilter

**An extender that adds Excel-style filter buttons to DataGridView column headers, with a value-list panel, a condition builder, and support for custom filter panels.**

## Installation

The extension is published on NuGet as **`Wisej-{version}-ColumnFilter`**, where `{version}` is the major version of Wisej.NET you use. For example, for Wisej.NET 4:

```
dotnet add package Wisej-4-ColumnFilter
```

Keep it at the same version as the `Wisej-4` package. See [Installing an extension](https://docs.wisej.com/extensions/#installation).
